# Профориентация: сайт диагностики

Стартовый набор для удалённой диагностики учеников 9–11 классов. Ученик проходит анкету на сайте
(на казахском, около 20 минут), ответы и посчитанные показатели попадают в вашу Google Таблицу.
По ним вы разбираете результат с учеником и составляете roadmap.

Диагностика — «2-нұсқа»: интерес к 14 областям → группы образовательных программ по списку НЦТ →
пара профильных предметов ЕНТ. Матрица предметов и вопросы о тревожности проверяют полученную пару.

## Что в папке

| `site/data/questionnaire.js` | Все вопросы и таблица «область → пара ЕНТ» |
| `site/scoring.js` | Правила подсчёта и все пороги |
| `site/i18n.js` | Тексты интерфейса на казахском и русском |

| `apps-script/Code.gs` | Скрипт, который пишет ответы в Google Таблицу |
| `apps-script/Summary.gs` | Лист «Сводка»: итоги по потоку и диаграммы |
| `tests/scoring.test.js` | Проверки подсчёта |

| `CLAUDE.md` | Контекст проекта для Claude Code |

## Шаг 1. Посмотреть сайт у себя

Откройте `site/index.html` двойным щелчком. Пока в `config.js` не указан адрес приёмника, сайт
работает в «сынақ режимі»: ответы никуда не уходят, в конце их можно скачать файлом.

Если что-то не открывается из файла, запустите локальный сервер из папки проекта:

```
cd site && python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Шаг 2. Подключить Google Таблицу

Названия пунктов меню в Google могут немного отличаться от написанных здесь.

1. Создайте новую Google Таблицу, например «Профориентация — ответы».
2. В меню таблицы: Extensions (Расширения) → Apps Script.
3. Удалите код в редакторе и вставьте содержимое `apps-script/Code.gs`. Сохраните.
4. Выберите функцию `selfTest` и нажмите Run. Google попросит разрешение на доступ к таблице —
   подтвердите. После запуска в таблице появятся листы `Raw`, `Responses`, `Scores` с тестовой строкой
   (её можно удалить).
5. Deploy → New deployment → тип Web app. Execute as: **Me**. Who has access: **Anyone**. Deploy.
6. Скопируйте Web app URL (заканчивается на `/exec`).

При каждом изменении `Code.gs` нужно выпускать новую версию: Deploy → Manage deployments → Edit →
New version. Адрес при этом остаётся прежним.

## Шаг 3. Соединить сайт с таблицей

1. В `site/config.js` вставьте адрес в `endpoint: "..."`.
2. Откройте сайт, пройдите анкету до конца и убедитесь, что в листах `Responses` и `Scores`
   появилась строка.
3. Если на последнем шаге сайт пишет «Жауаптар жіберілмеді», проверьте: адрес заканчивается на
   `/exec`, доступ стоит Anyone, после правок скрипта выпущена новая версия.

## Шаг 4. Опубликовать сайт

Папка `site/` — обычный статический сайт, её можно выложить на любой статический хостинг
(GitHub Pages, Netlify, Cloudflare Pages). Публиковать нужно только содержимое `site/`.
Проще всего попросить Claude Code: «опубликуй папку site на GitHub Pages» — он проведёт по шагам.

## Шаг 5. Раздать ссылку

**Коды доступа.** Анкету можно пройти только с одноразовым кодом (`requireCode: true` в `config.js`).

1. В таблице откройте лист `Codes` и впишите имена учеников в столбец `student`, по одному в строку.
   В `cohort` можно указать поток, например `lek-1`.
2. Меню «Профориентация → Выдать коды». В столбце `link` появится личная ссылка каждого ученика,
   код в ней уже подставлен.
3. Отправьте ученику его ссылку. Код привязывается к устройству, на котором ученик начал анкету:
   там можно прерваться и продолжить, на другом устройстве код не примут. После отправки код
   помечается в `used_at` и больше не работает.
4. Ученик сменил телефон или нужно пройти заново: очистите в его строке `device` (а если анкета
   уже отправлена — ещё `used_at` и `submission_id`).

В листе `Scores` у каждой анкеты есть `access_code` и `code_student` — имя из листа `Codes`.

- Название потока можно передавать в ссылке: `https://ваш-сайт/?c=lek-1`. Оно попадёт в столбец `cohort`.
- Ученик может прерваться: ответы хранятся в браузере на его устройстве до отправки.
- На общем компьютере следующий ученик должен нажать «Басынан бастау».

## Шаг 6. Что приходит в таблицу

- `Responses` — сырые ответы, одна строка на ученика.
- `Scores` — то, что сайт посчитал: возможные области, порядок, который поставил ученик, пары ЕНТ,
  состояние («бағыт айқындалып келеді» или «бағыт әлі ашық») и его причины, флаги качества,
  тревожность, чтение матрицы предметов.
- `Raw` — исходный JSON каждой отправки. По нему всё можно пересчитать заново, если поменяются пороги.

Расшифровка столбцов — в `docs/data-dictionary.md`. Для roadmap обычно достаточно листа `Scores`
и файла `docs/nct-groups.csv` (какие группы программ открывает пара).

Строки с `quality_valid = FALSE` не стоит разбирать как результат: ученик отвечал слишком быстро,
одинаково или провалил проверку внимания. Ему лучше дать пройти анкету ещё раз.

- [ ] Дать пройти 5–6 ученикам и спросить, как они поняли каждое утверждение.
- [ ] Получить согласие родителей (черновик — `docs/consent-template.md`; покажите юристу).
- [ ] Первый поток назвать пробным: опросник на учениках ещё не проверялся.
- [ ] Сверить `docs/nct-groups.csv` с актуальным списком НЦТ на год поступления.
- [x] Показывать ученику предварительный результат: решено, `showResultToStudent: true` (с v2.3).

## Что важно знать

- **Это не валидированный тест.** Честное название — «қызығушылық картасы». Все пороги в
  `site/scoring.js` поставлены по оценке и должны быть пересчитаны на данных первого потока.
- **Предметных срезов (раздел В) на сайте нет.** Их нужно собрать из заданий формата ЕНТ отдельно.
- **Адрес приёмника публичный**, но без действующего кода из листа `Codes` анкета не принимается.
- **Данные несовершеннолетних** хранятся в вашем аккаунте Google. Не открывайте таблицу по ссылке
  и не собирайте больше, чем нужно для разбора.

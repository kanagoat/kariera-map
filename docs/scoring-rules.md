# Правила подсчёта

То же самое записано кодом в `site/scoring.js`. Все числа — предварительные пороги, поставленные
по оценке погрешности коротких шкал; их нужно пересчитать на данных первого потока.

## 1. Качество ответов

Анкета считается недостоверной (`quality_valid = FALSE`), если верно хотя бы одно:

| Флаг | Условие |
|---|---|
| `attention` | неверный ответ на любую из двух проверок внимания (ZE1 ждёт 2, ZE2 ждёт 4) |
| `straightline` | 20 и более одинаковых ответов подряд среди 56 утверждений |
| `fast` | медиана времени на одно утверждение меньше 3 секунд |

Сайт всё равно отправляет такую анкету, чтобы вы видели попытку. Разбирать её как результат не стоит.

## 2. Балл области

1. Личное среднее — среднее по всем 56 утверждениям.
2. Балл области — среднее её четырёх утверждений минус личное среднее (столбцы `dev_*`).
   Плюс означает «интереснее, чем обычно для этого ученика».
3. Профиль «неинформативный» (`uninformative`), если личное среднее 4,3 и выше или 2,0 и ниже.
   Тогда сайт не предлагает области сам: ученик выбирает 2–4 из полного списка.

## 3. Возможные области

- Возможные области (`candidates`) — область с наибольшим баллом и все, что отстают от неё меньше
  чем на 0,8.
- Если их больше четырёх, профиль «широкий» (`wide`), показываются четыре верхние.
- Если кандидат один, для ранжирования показывается ещё вторая по баллу область.
- `rejected` — области с баллом −0,8 и ниже: «сейчас неинтересно».

Ученик сам расставляет показанные области по порядку и может добавить одну из остальных.

## 5. Матрица предметов

По каждому из трёх вопросов («оңай беріледі», «ұнайды», «қалдырар едім») балл предмета считается
как отклонение от среднего ученика по этому вопросу. «Высоко» — +0,5 и выше, «низко» — −0,5 и ниже.

| Значение `read_*` | Сочетание | Что делать |
|---|---|---|
| `like+can` | нравится и получается | поддерживает пару с этим предметом |
| `can-not-like` | получается, но не нравится | не рекомендовать пару только из-за хорошей оценки |
| `like-not-can` | нравится, но не получается | смотреть тревожность и срез; предмет не закрывать |
| `keep-not-like` | оставил бы, но не нравится | выбор ради пользы или под давлением; обсудить |
| `neutral` | без выраженного сочетания | — |
| `missing` | предмет не изучает | — |

Пара помечается (`flagged_pairs`), если у любого её предмета отклонение «ұнайды» ниже −1,0.

## 6. Тревожность

`anxiety_math` и `anxiety_text` — средние по трём утверждениям. Флаг страха (`fear_math`,
`fear_text`) — среднее 4,0 и выше. При флаге низкое «ұнайды» по предмету не считается
доказательством отсутствия интереса: предмет не закрываем, предлагаем срез без оценки и таймера.

## 7. Состояние

«Бағыт айқындалып келеді» ставится, только если нет ни одной причины из списка; иначе
«бағыт әлі ашық», а причины перечислены в столбце `reasons`.

| Причина | Условие |
|---|---|
| `uninformative` | неинформативный профиль |
| `wide` | широкий профиль |
| `many-pairs` | выбранные учеником области ведут больше чем к двум парам |
| `stated-differs` | пара, которую ученик назвал сам, не входит в полученные |
| `pair-disliked` | хотя бы одна пара помечена по матрице предметов |

Уровня «высокая уверенность» нет намеренно. Состояние — подсказка, с кем нужен отдельный разговор.

## 8. До и после курса (пока не реализовано)

Повторная анкета после курса сравнивается с первой: профили согласуются, если корреляция 14 баллов
областей выше 0,6 и хотя бы одна из двух верхних областей совпала. Это не проверка устойчивости:
между замерами идёт курс, который сам меняет интересы.

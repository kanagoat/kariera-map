# Столбцы таблицы

Листы создаются скриптом при первой отправке. Новые столбцы добавляются справа автоматически.

## Лист Responses — сырые ответы

| Столбец | Значение |
|---|---|
| `received_at` | время приёма на стороне Google |
| `submission_id` | код отправки; по нему отсекаются повторы |
| `submitted_at` | время отправки на устройстве ученика (UTC) |
| `cohort` | поток: из ссылки `?c=...` или из `config.js` |
| `version` | версия анкеты (v2.2 — добавлены русская версия и правки казахского текста) |
| `access_code` | одноразовый код из листа `Codes` (с v2.3). Есть и в `Responses`, и в `Scores` |
| `access_device` | случайная метка устройства, к которому привязан код (не персональные данные) |
| `code_student` | только в `Scores`: имя ученика из листа `Codes`, подставляет приёмник |
| `lang` | язык, на котором ученик проходил анкету: `kk` или `ru`. Есть и в `Responses`, и в `Scores`. Названия пар и областей в `Scores` всегда на казахском |
| `name`, `grade` | имя (как написал ученик) и класс 9/10/11. Столбец `school` был до v2.3, больше не собирается |
| `after9` | только для 9 класса: `school`, `college`, `unsure` |
| `plan` | о какой профессии думает (свободный текст) |
| `confidence` | уверенность в этом выборе, 0–100 |
| `stated_pair` | пара ЕНТ, которую ученик уже выбрал; пусто, если не выбрал |
| `teacher`, `teacher_subject` | рассматривает ли профессию учителя (`yes`/`maybe`/`no`) и предмет |
| `sport_art` | связывает ли профессию со спортом или искусством |
| `grant` | важность гранта: `must`, `prefer`, `any` |
| `consent` | отметка о согласии родителей |
| `ENG1` … `ART4` | 56 утверждений об интересах, 1–5; код области и номер утверждения |
| `ZE1`, `ZE2` | проверки внимания (верные ответы 2 и 4) |
| `rank_1` … `rank_4` | области в порядке, который поставил ученик (коды) |
| `added_field` | область, которую ученик добавил сам |
| `can_*`, `like_*`, `keep_*` | матрица предметов, 1–5; пусто, если предмет не изучает |
| `MA1`–`MA3`, `TA1`–`TA3` | тревожность: математика и письмо/устные ответы, 1–5 |
| `open_label`, `open_dislike` | открытые вопросы |
| `duration_sec` | время от начала до отправки, включая перерывы |
| `interest_median_ms` | медиана времени на одно утверждение |
| `user_agent` | браузер и устройство |

Коды предметов: `math`, `physics`, `informatics`, `chemistry`, `biology`, `geography`, `history`
(всемирная история), `law`, `foreign`, `language` (казахский или русский язык и литература).

## Лист Scores — посчитанное

| Столбец | Значение |
|---|---|
| `status` | «бағыт айқындалып келеді» или «бағыт әлі ашық» |
| `reasons` | почему направление открыто (см. `scoring-rules.md`, раздел 7) |
| `pairs` | пары ЕНТ, к которым ведут выбранные области |
| `ranking` | области в порядке ученика, включая добавленную |
| `candidates` | области, которые предложил подсчёт |
| `rejected` | области с явно низким интересом |
| `stated_pair`, `contradicts_stated` | названная учеником пара и расходится ли она с полученными |
| `flagged_pairs` | пары, в которых предмет сильно не нравится |
| `quality_valid`, `quality_flags` | достоверна ли анкета и какие флаги сработали |
| `attention_failed`, `longest_run`, `median_ms` | детали качества |
| `personal_mean` | личное среднее по 56 утверждениям |
| `uninformative`, `wide` | неинформативный или широкий профиль |
| `dev_ENG` … `dev_ART` | балл каждой области: отклонение от личного среднего |
| `anxiety_math`, `anxiety_text`, `fear_math`, `fear_text` | тревожность и флаги страха |
| `read_*` | чтение матрицы по предмету (см. `scoring-rules.md`, раздел 5) |
| `like_dev_*` | отклонение «ұнайды» по предмету |
| `teacher`, `sport_art`, `after9` | продублированы для удобства разбора |

## Лист Raw

`submission_id`, `received_at`, `json` — исходная отправка целиком. Нужен, чтобы пересчитать
показатели при изменении порогов.
